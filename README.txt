SHADYWARE WEBSITE — FULL BUILD

DEPLOY
1. Upload index.html, styles.css, script.js, README.txt, and the products folder to the ROOT of your GitHub repository.
2. In Render, use Static Site with the GitHub repository, branch main, Build Command blank, Publish Directory .
3. Every commit to main will redeploy if Auto-Deploy is enabled.

SITE CONTENT
- Home page, animated silver rain, responsive navigation, product search and filters
- Three separate product detail pages in /products/
- Changelog, team, creator program, FAQ, Discord links
- Optional synthesized ambient sound (only after a visitor clicks Turn it on)

EDIT PRODUCTS
Open script.js and edit the products array near the top. Keep each id matching its page filename in products/. Edit the matching products/<id>.html page for its full description and features.

EDIT CHANGELOG / FAQ
Edit the changes and faqs arrays in script.js.

TEAM IMAGES
The supplied iBB links are included exactly as provided and are clickable. iBB share-page URLs may not work as direct image sources in browsers; if an image does not display, replace the img src with the direct image URL from iBB (usually an i.ibb.co URL). The fallback initials will display otherwise.
